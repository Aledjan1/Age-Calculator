## Age Calculator ⏳

An interactive Age Calculator built with HTML, CSS, and JavaScript.

The application converts a person's age in year into month, weeks, days, and hours.

This project is part of my JavaScript learning journey, helping me strengthen my understanding of JavaScript fundamentals, DOM manipulation, and user input validation.

## Features 

- Calculate age in month, weeks, days, and hours
- Support whole numbers and decimal ages
- Validate user input
- Display an alert for empty or negative values
- Reset results when invalid input is entered
- Format large numbers with commas using British English formatting
- Responsive and user-friendly design

## Technologies Used

- HTML5 - Page structure
- CSS3 - Styling and responsive layout
- JavaScript - Calculation, validation, and DOM manipulation

## How It Works

1. Enter your age in years.
2. Click the Calculate Age button.
3. JavaScript converts the entered value into a number.
4. The calculator displays your approximate age in month, weeks, days, and hours.
5. Invalid input triggers an error message and reset the results.

Note: Calculations are approximate, based on 365 days and 52 weeks year.
